# NovelTTS

NovelTTS 是一个 Android 文本转语音引擎。它可以导入语音包并使用在线 Edge Read Aloud 或微软 Embedded Speech 合成音频，也可以作为 Android 系统 TTS 引擎供阅读器等应用调用。

## 功能

- 作为系统 TTS 引擎提供语言、音色查询和文本合成。
- 导入原版 MultiTTS 语音包；支持本地 ZIP 和在线目录。
- 使用 Edge Read Aloud 在线语音，或使用微软 Embedded Speech 离线语音。
- 在工作台选择旁白和对话音色，并预览分段结果。
- 使用角色规则、文本替换规则和纯标点过滤处理朗读文本。
- 通过 Android 分享菜单将文本发送到 NovelTTS 朗读。

## 验证状态与要求

最近记录的验证结果：40 个 JVM 单元测试通过，Debug APK 构建成功。微软离线音色“晓晓”已在提供合法许可证和所需本地原生库的设备环境中验证合成。不同设备、语音包和系统 TTS 调用方式仍可能需要单独验证。

- Android 最低版本：Android 8.0（API 26）。
- 当前 APK 仅打包 `arm64-v8a`。
- Edge 在线语音需要网络连接。
- 微软 Embedded Speech 离线语音需要用户自行提供合法许可证、模型文件和匹配版本的原生库。相关资源不随本仓库分发。

## 安装语音包与设置系统 TTS

1. 安装并打开 NovelTTS。
2. 在“语音包”页面导入原版语音包 ZIP，或配置在线目录并下载语音包。
3. 打开 Android 系统的“文字转语音输出”设置，将首选引擎设为 NovelTTS。不同设备的设置名称和位置可能不同。
4. 在阅读器或其他应用中选择 NovelTTS 提供的音色并开始朗读。

原版语音包 ZIP 的根目录需要包含 `config.yaml` 和 `engines.yaml`。微软离线语音包还需包含相应模型文件。旧版 `pack.json` 包可用于兼容安装，但不会注册可由 NovelTTS 合成的系统音色。

语音包格式、在线目录字段和安装限制见[语音包说明](docs/VOICE_PACKS.md)。

## 主要界面

应用提供工作台、语音包、角色、替换和设置页面，用于选择音色、管理语音包与文本规则，以及配置引擎选项。

## 当前限制

- Edge 在线语音使用在线服务，需保持网络可用；上游服务协议可能变化。
- 微软离线语音只有在本地模型、原生库和合法许可证均已配置时才能合成。
- 角色识别依赖用户配置的显式规则；应用不会自动识别小说人物或自动分配角色音色。
- 不支持原版 MultiTTS 的 JavaScript 插件与配置扩展。
