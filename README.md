# NovelTTS

**面向小说多角色朗读的 Android 文本转语音引擎。**

为旁白和已配置的人物选择不同的声音，让同一个人物保持自己的配音。在应用内直接试听，也可以通过 Android 系统 TTS 或 HTTP 接入阅读器。

[下载 APK](https://github.com/mrliergou/Noveltts/releases) · [快速开始](#快速开始) · [按书配置人物](#按书配置人物) · [使用文档](#使用文档)

Android 8.0+ · arm64-v8a · Edge 在线语音 / 微软 Embedded 离线语音

> 项目仍在开发中。本文介绍当前源码，下载页的 APK 不一定包含全部开发功能，请以对应版本说明为准。应用不内置音色或模型，需要自行导入语音包。

## 让人物的声音保持一致

为一本书添加已知人物和别名，再选择一组声音，NovelTTS 会为尚未绑定声音的人物分配音色并保存。你也可以手动指定配音。

例如，先配置「林舟」和「许宁」两个角色，再朗读这样的文本：

> 夜色渐深，窗边仍亮着一盏灯。  
> 林舟说：“明天一早就出发。”  
> 许宁说：“好，我在桥头等你。”

在这个配置示例中，叙述使用旁白音色，两句对白分别使用林舟和许宁的声音。分段预览可以查看每句话的角色归属；根据上下文无法明确判断的片段会显示不确定提示。

- **按书保存人物。** 每本书有独立的人物表、别名和声音池，人工修改、改声与合并都在本书内进行。
- **保存配音绑定。** 重启或调整声音池顺序不会重新分配已绑定人物。音源暂时不可用时可回落到默认对话音色，原绑定仍保留。
- **沿用同一套配置。** 应用内朗读、系统 TTS 和 HTTP 共用文本规则与合成逻辑。

**当前人物需要手动添加。** 说话人归属是在已配置人物之间判断，不会自动建立整本书的人物表。没有明确说话线索、只用代词或连续问答的文本仍可能判断不准。

## 快速开始

### 1. 导入声音，先试听

1. 从 [Releases](https://github.com/mrliergou/Noveltts/releases) 下载 APK，安装并打开 NovelTTS。
2. 进入「语音包」，导入本地 ZIP，或通过直链、在线目录下载语音包。
3. 选择可用音色试听，再到工作台设置旁白与默认对话声音，输入一小段文本开始朗读。

目前可以合成的音源只有两类：

| 音源 | 使用条件 |
| --- | --- |
| Edge Read Aloud | 需要网络；使用非官方接口，上游变化可能影响可用性 |
| 微软 Embedded Speech | 需要用户自行提供合法许可证、模型和版本匹配的原生库；这些资源不随仓库分发 |

语音包能够导入，不代表其中所有引擎都能发声。缺少后端、模型或许可证的音色不会作为可用音色提供给系统。包的制作与导入规则见 [语音包格式](docs/VOICE_PACK_FORMAT.md)。

### 2. 接入阅读器

**使用系统 TTS：** 打开 Android 的「文字转语音输出」设置，将首选引擎设为 NovelTTS，再在支持系统 TTS 的阅读器中选择音色并开始朗读。不同设备的设置名称和位置可能不同。

**使用 HTTP：** 在设置中启用本机 HTTP 转发，可查询音色并请求 WAV 音频，也可导出面向 [阅读（Legado）](https://github.com/LegadoTeam/legado)的 HttpTTS 配置。导出能力已实现，阅读器端的 HTTP 导入与朗读联动仍需验收；鉴权和参数见 [HTTP 接口](docs/HTTP_API.md)。

也可以从其他应用的 Android 分享菜单，将文本发送到 NovelTTS 朗读。

## 按书配置人物

以下流程适用于包含「书籍角色」页面的版本：

1. **新建并选择书籍。** 进入「书籍角色」，为当前阅读的小说建立人物表。
2. **选择声音池。** 连续勾选并试听几个声音，统一保存；之后可以调整顺序。
3. **添加人物和别名。** 为已知人物填写姓名及常用称呼，由声音池分配，或手动指定音色。
4. **预览后开始朗读。** 用带有明确说话线索的短段落检查配音，必要时修改人物或合并别名。

换书时，请在 NovelTTS 中手动切换当前书籍。工作台、系统 TTS 和 HTTP 共用这个选择，新朗读才使用新配置；进行中的朗读和阅读器已排队的音频不会随之重建。当前不根据正文自动识别书名。

不选择书籍时，可以继续使用全局角色规则。多音字或特殊读法可通过文本替换规则调整；规则支持普通文本、正则，以及旁白、对话或指定角色等作用范围。

## 日常朗读与管理

- **播放控制：** 暂停、继续、前后切段、逐段试听与冷启动后的断点续读。应用内整篇朗读会预先合成下一段，减少段间等待。
- **声音管理：** 搜索、筛选、收藏、启停音色，调整语速、音调和音量；声音与倍率可按角色设置。
- **数据管理：** 阅读方案、缓存、备份还原和诊断日志导出；备份默认不包含凭据。
- **应用体验：** 白天、夜间、跟随系统三档主题；背景音乐仅用于应用内播放。

## 当前状态与边界

当前源码已接入按书人物、声音池固定分配、人工纠错和三入口共用配置。主要书籍交互、实际播放、主题切换及暂停续读已有 Android 13 真机验证；这不代表所有设备、阅读器和场景都已完成验收。

- **适配仍在推进。** 小屏、大字号、TalkBack、较新 Android 版本与其他厂商 ROM 尚未完整覆盖。
- **复杂归属仍有限制。** 自动发现人物和整本扫描尚未实现；外部阅读器的长引语切块、预排队及阅读器内换书仍需补测。
- **合成需要等待。** 首段要等合成完成后才播放，尚未实现边接收边播放；合成等待与音频播放时长是不同指标。
- **兼容有明确范围。** 当前只有 `edgetts` 与 `microsoft` 后端可用，不执行 MultiTTS 的 JavaScript 插件，也不兼容 tts-server-android 的配置。

后续方向见 [路线图](docs/ROADMAP.md)。系统音色 ID 中的 `multitts:` 前缀是为保留已有音色选择而沿用的兼容标识。
