# NovelTTS

NovelTTS 是一个面向小说朗读的 Android 文本转语音（TTS）引擎，使用 Kotlin 与 Jetpack Compose 编写。它导入语音包后直接合成音频，并注册为 Android 系统 TTS 引擎，供阅读器等应用调用；朗读时把旁白与引号内的对话分开，让不同角色使用不同音色。

> 项目处于开发阶段，历史发布提供的是调试 APK，尚无正式签名的 release 版本；工作区修复不等于已发布。在线音源使用**非官方**的 Edge Read Aloud 接口，上游协议随时可能变化。

## 功能

**合成与接入**

- 注册为 Android 系统 TTS 引擎，提供语言查询、音色列表与文本合成。
- 两类合成后端：Edge Read Aloud 在线语音、微软 Embedded Speech 离线语音。
- 本机 HTTP 转发：音色查询、WAV 合成，并可导出[阅读（Legado）](https://github.com/LegadoTeam/legado)的 HttpTTS 配置。
- 通过 Android 分享菜单把文本发送到 NovelTTS 朗读。
- 应用内朗读、系统 TTS、HTTP 三个入口共用同一套规则与合成链路。

**多角色朗读**

- 旁白与对话自动分段，各自设置音色、语速、音调和音量。
- 自定义角色：一个角色可配置多个称呼与多个音色（固定或轮转）。
- 说话人归属：根据引号前后的旁白判断一句对话属于哪个已配置的角色；判断不够确定的片段会在分段预览里标出。
- 文本替换规则（普通 / 正则，可作用于全文、旁白、对话或指定角色）与纯标点过滤。
- 规则分组、拖拽排序、草稿测试，导入时预览冲突。

**语音包与音色**

- 导入原版 MultiTTS 语音包（本地 ZIP、直链或在线目录），安装失败自动回滚。
- 浏览、搜索、筛选并试听全部音色；逐音色设置别名、收藏、启停与默认倍率。

**播放与数据**

- 暂停、继续、上一段 / 下一段、逐段试听，冷启动后断点续读。
- 应用内朗读可在关闭界面后继续，支持音频焦点、媒体控制和耳机拔出暂停；中断行为受设备音频策略影响。
- 整篇朗读时提前合成下一段，缩短段间等待。
- 阅读方案、音频缓存、背景音乐（仅应用内播放）、诊断日志导出。
- 备份与还原：事务写入，失败回滚；凭据默认不导出。
- 白天、夜间、跟随系统三种主题模式。

## 运行要求

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 8.0（API 26）及以上 |
| CPU 架构 | 仅 `arm64-v8a` |
| Edge 在线语音 | 需要网络连接 |
| 微软离线语音 | 需要用户自行提供合法的 Embedded Speech 许可证、模型文件和版本匹配的原生库；这些资源不随本仓库分发 |

应用本身不内置任何音色或模型，音色全部来自用户导入的语音包。

## 快速上手

1. 安装并打开 NovelTTS。
2. 在「语音包」页面导入语音包 ZIP，或填写在线目录地址后下载。
3. 打开 Android 系统的「文字转语音输出」设置，把首选引擎设为 NovelTTS（不同设备的名称和位置可能不同）。
4. 在阅读器或其他应用里选择 NovelTTS 提供的音色，开始朗读。

想让不同角色用不同音色：在「工作台」的朗读角色里添加角色，填入称呼并选择音色，分段预览会显示每句话判给了谁。

语音包的目录结构与字段见 [语音包格式](docs/VOICE_PACK_FORMAT.md)；通过 HTTP 调用见 [HTTP 接口](docs/HTTP_API.md)。

### 关于语速与时长

合成等待时间和音频播放时长是两个指标。外部客户端没有显式设置语速 / 音调时会继承 Android 系统设置，输出时长随之变化。对比应用内、系统 TTS 与 HTTP 的表现时，请固定文本、音色、语速、音调、音量和缓存条件。

## 项目状态

核心链路已经可用：Edge 与微软 Embedded 两个后端、系统 TTS、多角色文本管线、HTTP 转发、缓存、备份和日志均已实现，并在一台 Android 13 真机上验证过主要流程。

尚未做到的部分（详见[路线图](docs/ROADMAP.md)）：

- 只在一台设备上验证过，Android 14 及以上版本和其他厂商 ROM 没有覆盖。
- 百度、讯飞等语音包可以导入，但对应的合成后端还没有实现。
- 首段仍要等整段合成完成才开始播放，没有做边收边播。

## 已知限制

- Edge 在线语音依赖非官方接口，上游变化可能导致不可用。
- 微软离线语音只有在本地模型、原生库和合法许可证都配置好之后才能合成；缺许可证的音色在应用内会标出原因，不会提供给系统。
- 当前只有 `edgetts` 和 `microsoft` 两类音色能合成。BDoTTS、讯飞配音、BDeTTS 番茄畅听等语音包可以导入，但不能发声，也不会注册为系统音色。
- 说话人归属只在用户已配置的角色之间判断，不会自动发现小说里的新人物，也不会自动分配音色。没写明说话人的连续问答、只用代词指代的对话可能判断不准。
- 不支持原版 MultiTTS 的 JavaScript 插件与配置扩展，不兼容 tts-server-android 的配置。
- HTTP 只输出 WAV。阅读应用的配置已能导出，实际导入与朗读联动尚未验收。
- 转接设备上其他 TTS 引擎的本地桥接尚未接通，设置入口已隐藏。
- 系统音色 ID 的前缀是 `multitts:`，这是为了不让已保存的音色选择失效而有意保留的，不是遗漏。

## 关于本仓库

本仓库目前用于**分享项目源码**，包含 `app/src/main` 下的产品源码与资源。以下内容按 `.gitignore` 保留在作者本机，不随仓库分发：

- Gradle 构建配置（`build.gradle.kts`、`settings.gradle.kts`、`gradle.properties`）与 Gradle Wrapper；
- 单元测试与设备测试；
- 微软 Embedded Speech 的原生库、模型和语音包；
- 内部交接与设计文档。

因此**只克隆本仓库不能直接构建出 APK**。自行补齐构建配置所需的版本信息见[架构说明](docs/ARCHITECTURE.md#技术栈)。

仓库暂未附带开源许可证文件；在许可证明确之前，默认保留所有权利。
